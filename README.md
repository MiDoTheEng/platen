# Platen

A typewriter for your phone. The page feeds up line by line as you type, the type bar
strikes each letter, every character is ink-stamped slightly differently, and the
keys, carriage return and end-of-line bell all make their sounds.

- Pages save themselves; tap one on the home screen to keep typing, hold it to delete.
- 3,000 characters per page, counted at the top.
- Tool pill: lamp mode (dark room, a cone of warm light), sound on/off, paper tone
  (rose, cream, white, blue), type size, keyboard show/hide.
- Drag the page down to read back what has scrolled away.
- Share a page as text, as an image of the typed sheet, or copy it.

Build: every push runs GitHub Actions and attaches `Platen.apk` to the run
(Actions → latest run → Artifacts). Plain Java, no libraries.
